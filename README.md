# 播浪

中文名：**播浪** · 前缀 `livewave` · 端口 **6400 / 11400**

## 骨架

**互动事件入流 → 事件时间水位线推进 → 热度窗关闭发射 → 迟到修正/撤回 → 窗输出与撤回互证**

皮：直播间点赞/送礼互动。去皮是事件时间窗计算 + 允许迟到与撤回，不是直播运营后台 CRUD，不是点击会话空闲切开。

## 冒烟

```bash
docker compose up -d --build
# http://127.0.0.1:6400
# 入流 → 灌「准时热度样例」→ 水位线/热度窗 → 再灌「迟到修正样例」看撤回 → 贯验
```

## 主链对象

| 对象 | 作用 |
| --- | --- |
| 互动事件 | 带事件时/处理时的点赞送礼 |
| 水位线 | 每房事件时水位 + 允许迟到秒 |
| 热度窗 | 翻滚窗；开启累计，关闭发射 |
| 撤回单 | 已关闭窗被允许迟到事件修正 |
| 旁路匣 | 超允许迟到 |
| 窗贯验 | 窗合计 ↔ 事件合计 ↔ 末次撤回 |

## 空桩（邻题扩展）

双钟水位线、允许迟到策略、撤回合并替换、房间级水位线、滑动窗切分、送礼加权热度、关窗并发半截、水位线回退禁改、旁路升格重放、多房串扰隔离、撤回幂等键、处理时乱序缓冲、窗键对齐互证、热度上限截断、开播闭播切流。

## 已落地邻题：空窗发射策略

水位越过某窗窗止而该窗无事件时，按全局唯一站规「空窗发射策略」处置，两口径可切换且可证：

- **发射零窗**（默认）：无事件也关闭，物化零赞/零送/零笔数的零窗行（`热度窗.空窗=1`，冻结 `空窗策略快照`）；
- **跳过空窗**：无事件不建行，水位推进不失败；该口径下任何空窗行都判为冒充发射（invalid）。

只读接口 `GET /api/空窗策略`（策略）、`/api/空窗策略/窗键?窗键=`（窗键存在/关闭态/valid）、`/api/空窗策略/校验`（关窗扫描完整性）；`POST /api/空窗策略/切换` 留履历，只影响此后发射，历史零窗凭快照不暗改。策略未定时装载失败闭（HTTP 409，整批回滚，无半截空窗）；整批 `BEGIN IMMEDIATE` 事务与写锁重试保证并发不撕裂。夹具 `空窗水位跳跃样例` 制造跨空区间水位跳跃。
